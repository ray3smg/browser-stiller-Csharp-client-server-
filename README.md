консольное приложение на C#, предназначенное для автоматизированного сбора пользовательских данных с компьютера: данных браузеров, файлов с рабочего стола и настроек FTP-клиентов. Все собранные данные упаковываются в ZIP-архив и отправляются на удалённый сервер.

⚠️ ! Данный проект создан исключительно в образовательных целях, для изучения принципов работы систем сбора информации и сетевого взаимодействия.

1. Данные браузеров

2. Файлы с рабочего стола
Собираются документы со следующими расширениями:
.pdf, .txt, .sql, .doc, .docx, .xls, .xlsx, .csv, .json, .xml, .conf, .config, .ini
Файлы копируются в папку Desktop/ внутри рабочей директории.
